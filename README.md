# Safe local Google Flow MCP

## Проект: цель и текущая стадия

**Окончательная цель:** приватный, безопасный и переносимый MCP-сервер, который
можно установить из этого GitHub-репозитория и подключить к уже запущенному Google
Chrome для работы с Google Flow.

**Текущая стадия:** первая версия опубликована в private GitHub-репозитории: stdio
MCP, проверка loopback CDP, allowlist `https://labs.google/*`,
подготовка/подтверждение генерации, ожидание и безопасное сохранение MP4. Unit-тесты,
линтер и `npm audit` проходят. Следующий этап — проверить установку из чистой папки
без реальной генерации и при необходимости адаптировать UI-селекторы после ручной
проверки в Google Flow.

**Как будет работать проект:** исходный код и документация живут в GitHub. Каждый
пользователь клонирует временную локальную копию только для запуска Node.js и
подключения к собственному Chrome; Chrome-профиль, сессии и видео не попадают в
GitHub.

## Установить через ИИ-агента

После публикации скопируйте этот prompt в любой ИИ-агент. Замените URL только если
репозиторий будет переименован.

```text
Установи безопасный локальный MCP для Google Flow из приватного репозитория:
https://github.com/shaekhovismagil-bit/google-flow-safe-mcp

Сначала прочитай README и выполни все описанные там требования безопасности.
Клонируй репозиторий в выбранную мной локальную папку, выполни npm ci, npm test,
npm run lint и npm audit. Объясни, как Я САМ запускаю отдельный Chrome-профиль с
CDP только на 127.0.0.1:9222, но не запускай Chrome и не читай профиль.

Не копируй и не читай Cookies, Login Data, Local State, пароли, токены или сессии.
Не меняй настройки MCP-клиента без моего отдельного подтверждения: вместо этого
покажи точную команду подключения. Автоматизируй только https://labs.google/*.
Не используй stealth, обход CAPTCHA или anti-detection. Любое действие с расходом
кредитов Google Flow выполняй только после моего явного подтверждения.
```

Локальный MCP-сервер по stdio для уже запущенного Google Chrome. Он подключается
только к CDP на `127.0.0.1`, автоматизирует только `https://labs.google/*` и
сохраняет готовые MP4 в `outputs/videos/` этого проекта.

## Безопасность

- Chrome запускает и авторизует сам пользователь — сервер не запускает браузер.
- Не копируются и не читаются профиль Chrome, `Cookies`, `Login Data`, `Local State`,
  пароли, токены или сессии.
- Любые URL вне `https://labs.google/*` и CDP вне `http://127.0.0.1:<port>` отклоняются.
- Нет upload-путей, изменения конфигураций MCP-клиентов, stealth/anti-detection или
  обхода CAPTCHA.
- `flow_generate_video` только заполняет форму, пока явно не задано `confirm: true`.
- Логи не содержат полный prompt, cookies или URL с query/hash.

## Установка

Требуется Node.js 20+.

```powershell
npm install
npm test
npm run lint
npm audit
```

Скопируйте `config.example.json` в `config.json` и при необходимости измените только
локальный `cdpPort`.

Скопируйте текст ниже в Codex, Claude Code, Cursor Agent или другого агента. Агент
может скачать и проверить проект, но не должен запускать Chrome, копировать профиль
или менять конфигурацию вашего клиента без отдельного подтверждения.

```text

приватного GitHub-репозитория. Работай только в выбранной мной локальной папке.

2. Установи зависимости через npm ci, затем выполни npm test, npm run lint и npm audit.
3. Скопируй config.example.json в config.json. Разрешён только CDP-адрес

   или hostnames.
4. Объясни мне, как Я САМ должен запустить Google Chrome с отдельным профилем,
   --remote-debugging-address=127.0.0.1 и --remote-debugging-port=9222. Не запускай
   Chrome, не читай и не копируй Cookies, Login Data, Local State, пароли, токены
   или данные профиля.
5. Запусти MCP-сервер только по stdio. Не изменяй конфиги Codex, Claude Desktop,
   Cursor, OpenCode или других клиентов: покажи мне точную команду/запись, а я

7. Перед каждым действием, которое может расходовать кредиты Google Flow, запроси
```

## Запуск Chrome пользователем

Создайте отдельный профиль Chrome вручную, войдите в Google Flow и самостоятельно
запустите Chrome с loopback CDP, например:

```powershell
& "$env:ProgramFiles\Google\Chrome\Application\chrome.exe" `
  --remote-debugging-port=9222 `
  --remote-debugging-address=127.0.0.1 `
  --user-data-dir="C:\path\to\your\separate-flow-profile"
```

Сервер не выполняет эту команду и не принимает путь к профилю.

## MCP-клиент

Запустите сервер командой `node D:\Рабочий стол\MCPAgent+Flow\src\index.js` в
настройках любого MCP-клиента. Конфигурации клиентов этот проект не редактирует.

Инструменты: `flow_connect`, `flow_status`, `flow_generate_video`,
`flow_wait_for_video`, `flow_download_video`, `flow_disconnect`.

`flow_download_video` возвращает абсолютный путь, `file://` URI, размер, MIME
`video/mp4` и текст, который агент может использовать для вложения. Возможность
автоматического прикрепления локального видео зависит от конкретного MCP-клиента.
